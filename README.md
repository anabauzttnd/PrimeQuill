# PrimeQuill

PrimeQuill leverages distributed, event-driven microservices architecture with a scalable API gateway orchestrator.

The key benefits of using PrimeQuill include:

- PrimeQuill leverages distributed, event-driven microservices
- architecture with a scalable API
- gateway orchestrator

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PrimeQuill.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure PrimeQuill, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
